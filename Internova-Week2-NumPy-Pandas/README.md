# Internova Week 2 - NumPy & Pandas for Data Analytics

## 📌 Project Overview

This repository contains my **Week 2 Data Analytics Internship Assignment**, focused on **NumPy and Pandas for Data Analytics**.

The assignment provides practical experience in working with numerical arrays, structured datasets, data inspection, data cleaning, filtering, sorting, dataset merging, GroupBy analysis, Pivot Tables, and exporting processed data.

The project also includes a **Mini Data Analysis Project based on Student Performance data**, where the complete data analysis workflow is demonstrated using Python, NumPy, and Pandas.

- Create and manipulate Pandas Series and DataFrames.
- Read and inspect CSV datasets.
- Select, filter, and sort data.
- Identify and handle missing values.

- Perform GroupBy analysis.
- Create Pivot Tables.

- Perform a complete basic data analysis project.
