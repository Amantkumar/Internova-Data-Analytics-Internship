# Week 3 — SQL & Excel for Data Analytics

## 📊 Data Analytics Internship Project

This repository contains my Week 3 Data Analytics Internship assignment focused on **SQL and Microsoft Excel for Data Analytics**.

The project covers practical SQL querying, data filtering, sorting, aggregation, grouping, joins and subqueries along with Excel-based data formatting, functions, lookups, Pivot Tables and charts.

## 🎯 Objectives

The main objectives of this assignment are:

- Learn fundamental SQL database operations.
- Retrieve data using SELECT statements.
- Filter and sort records using SQL.
- Apply aggregate functions such as COUNT, SUM, AVG, MIN and MAX.
- Use GROUP BY and HAVING for grouped analysis.
- Understand and implement SQL JOIN operations.
- Solve analytical problems using subqueries.
- Format and organize data in Excel.
- Use Excel sorting and filtering.
- Apply IF, COUNTIF and SUMIF functions.
- Use VLOOKUP and XLOOKUP.
- Create Pivot Table summaries.
- Create charts for data visualization.
